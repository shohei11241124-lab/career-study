# キャリコン合格ナビ

国家資格キャリアコンサルタント試験へ向けた日本語の学習管理アプリです。

## 現在の実装

- 2026/11/17〜2027/3/6の110日分、4段階、毎日60分の計画
- 今日の学習、日別計画、月間・週間カレンダー、進捗
- 完了チェック・時間・正答数・問題数・理解度・苦手分野・メモ
- 日別タスクの編集（元の計画はplan.jsに保持）
- 端末内保存、JSONバックアップ・復元、配色切替、ホーム画面用manifest

教材ページは未割当です。分野名は目次との照合前の仮テーマです。
記録はブラウザのlocalStorageだけに保存され、端末間同期はまだありません。

## 公開設定（iPadのSafariから）

1. GitHubでこのリポジトリの **Settings** を開く。
2. **Pages** を開く。
3. **Build and deployment → Source** で **GitHub Actions** を選ぶ。
4. **Actions → Deploy GitHub Pages → Run workflow** から実行する。
5. 完了後、Pages画面に表示されたURLを開く。

予定URL: https://shohei11241124-lab.github.io/career-study/
※ 実際の公開状態はActionsの成功とPages画面で確認してください。

Safariの共有ボタンから「ホーム画面に追加」で起動できます。オフライン動作はまだ対応していません。

## 開発

ビルド不要のHTML/CSS/JavaScriptです。サブパス対応の相対URLとハッシュによる画面切替を使用しています。
`npm test` で日付・計画の基本検証を実行できます。

## 次の開発段階

誤答単位の復習管理、過去問・論述・面接の専用記録、未完了の再配分、教材目次登録、試験日と学習時間の変更。
その後にSupabaseのメールログイン・RLS・同期・保存失敗時の再送を実装し、実端末で同期を検証します。
Supabaseの秘密鍵やパスワードはリポジトリに保存しません。
