# キャリコン合格ナビ

国家資格キャリアコンサルタント試験へ向けた日本語の学習管理アプリです。

## 現在の実装

- 2026/11/17〜2027/3/6の110日分、4段階、毎日60分の計画
- 今日の学習、日別計画、月間・週間カレンダー、進捗
- 完了チェック・時間・正答数・問題数・理解度・苦手分野・メモ
- 日別タスクの編集（元の計画はplan.jsに保持）
- 端末内保存、JSONバックアップ・復元、配色切替、ホーム画面用manifest

教材の全26節とページ範囲を登録済みです。一問一答は対応する節を表示し、未提供の問題番号は生成しません。
記録はブラウザのlocalStorageだけに保存され、端末間同期はまだありません。

## 公開設定（iPadのSafariから）

1. GitHubでこのリポジトリの **Settings** を開く。
2. **Pages** を開く。
3. **Build and deployment → Source** で **GitHub Actions** を選ぶ。
4. **Actions → Deploy GitHub Pages → Run workflow** から実行する。
5. 完了後、Pages画面に表示されたURLを開く。

予定URL: https://shohei11241124-lab.github.io/career-study/
※ 実際の公開状態はActionsの成功とPages画面で確認してください。

Safariの共有ボタンから「ホーム画面に追加」で起動できます。オフライン動作はまだ対応していません。

## 開発

ビルド不要のHTML/CSS/JavaScriptです。サブパス対応の相対URLとハッシュによる画面切替を使用しています。
`npm test` で日付・計画の基本検証を実行できます。

## 次の開発段階

誤答単位の復習管理、過去問・論述・面接の専用記録、未完了の再配分、試験日と学習時間の変更。
その後にSupabaseのメールログイン・RLS・同期・保存失敗時の再送を実装し、実端末で同期を検証します。
Supabaseの秘密鍵やパスワードはリポジトリに保存しません。

## 実技・受験手続きの追加

12月から毎週火曜にChatGPTロールプレイ、木曜に論述を通常60分の中に配置。
2月から土曜に計時模擬面接と口頭試問を配置し、直前期も計時練習します。
福岡の講座は1月・2月各1件、日付未定の別枠です。
「日別スケジュール」または「カレンダー」の「予定・状況を編集」から、日付・状態・予約・会場・費用・講師フィードバックを保存できます。
日付未定の講座はカレンダー下の一覧に表示し、開催日を入力すると該当日に表示します。
受験手続きの日付は個人の作業予定です。出願期限と試験日は公式情報未確認のため仮予定表示です。
学習タスクの「予定日を変更」で移動すると両画面に反映し、移動した日の合計時間は増減します。
受験手続きの完了率は学習とは別に集計します。
旧データの記録済み日と編集済み計画は保持し、未記録の既定計画へ実技練習を追加します。
バックアップは追加データも含み、旧形式のバックアップも読み込めます。

## 教材目次と日別範囲

textbook.jsにユーザー提供の4章26節を登録。長い節を最大10ページの38範囲に分け、基礎44日間に38回の学習と6回の週次復習を配置します。
知識定着期に2周目、その後に計時過去問と総復習を確保。毎日の既定合計は60分です。
設定画面「登録済みの教材目次」で全章・節・ページを確認できます。
旧端末データは記録と独自編集を保存したまま、表示時に仮表示を具体的な教材範囲へ置換します。移動済みタスクのIDも変えません。
